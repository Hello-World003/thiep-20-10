# Thiệp điện tử 20/10 💌

## Có gì trong bộ này?
- `index.html`: trang thiệp điện tử có nút mở thiệp, lời chúc và hiệu ứng cánh hoa.
- `tao-qr.html`: trang tạo mã QR PNG từ đường link thiệp sau khi đăng lên mạng.

## Chỉnh lời chúc
Mở `index.html` bằng VS Code hoặc trình soạn thảo văn bản. Tìm các đoạn chữ trong thẻ `<p>` và thay bằng lời chúc của bạn. Tìm `— Đức` nếu muốn đổi chữ ký.

## Đăng miễn phí bằng GitHub Pages
1. Đăng nhập hoặc tạo tài khoản tại https://github.com/ .
2. Tạo repository mới tên `thiep-20-10` (có thể để Public).
3. Tải lên **hai file `index.html` và `tao-qr.html`**. Không bắt buộc tải README.
4. Vào **Settings → Pages**. Ở phần Build and deployment, chọn **Deploy from a branch**; Branch chọn `main`, folder chọn `/(root)`, rồi bấm Save.
5. Chờ GitHub tạo trang. Đường link thường có dạng `https://TEN-TAI-KHOAN.github.io/thiep-20-10/` (thay TEN-TAI-KHOAN bằng username của bạn).
6. Mở đường link trên điện thoại để thử thiệp.
7. Mở trang `https://TEN-TAI-KHOAN.github.io/thiep-20-10/tao-qr.html`, dán link trang thiệp vào ô và bấm **Tạo mã QR**, rồi tải ảnh PNG.
8. Dùng một điện thoại khác quét thử QR trước khi gửi.

## Lưu ý
- QR chỉ hoạt động khi đường link trang thiệp đã được đăng công khai và truy cập được.
- Không đưa thông tin riêng tư hoặc thông tin nhạy cảm lên trang công khai.
- Nếu không muốn chữ ký là “Đức”, sửa trực tiếp trong `index.html` trước khi đăng.
